# Description

The so_long project is about creating a 2D game using minilibx features.
It converts a text file to a playable game map, and displays the number 
of moves your character performs.  

# Instructions

To compile this program, open a terminal in so_long folder, then type make.
To open the program, type ./so_long followed by a text file whose name ends by '.ber'.
Example : ./so_long map.ber
